# Applied Cryptography

Labs, exercises, and implementations from my cryptography course at Université Mundiapolis.

## Contents

- `classical-ciphers/tp01/` - Caesar & Vigenère in C (TP N°1)
- `symmetric/` - block and stream ciphers (e.g. AES, modes of operation)
- `asymmetric/` - RSA, Diffie-Hellman, key exchange
- `hashing/` - hash functions, HMAC, integrity checks
- `signatures/` - digital signatures and verification
- `notes/` - class notes and summaries

## Goals

- Understand how the algorithms work, not just how to call a library
- Implement core concepts from scratch where possible
- Compare my implementations with standard libraries

## Usage

```bash
git clone https://github.com/AnouarMohamed/applied-cryptography.git
cd applied-cryptography
# each folder has its own instructions
```

## Disclaimer

This repo is for learning only. Do not use these implementations in production. Use well-tested libraries instead.
